# 图片来源与归属登记

**规则：本站不使用来源不明的图片。** 每加入一张历史素材，必须在下表登记编号、来源、许可状态与原始链接。没有登记的图片不允许出现在 `public/` 或内容里。

## 许可判定纪律（查证过的事实，别凭印象）

- **Wellcome Collection**：同一站点内**混装**许可。抽样 100 条解剖类藏品的结果是 PDM 55 / CC BY 38 / CC BY-NC 2 / In copyright 5——**不能按站点推定，只能逐件读 `license` 字段**。
  - 可用：`pdm` / `cc0`（无限制，不要求署名）、`cc-by`（可用，需署名）
  - 不取：`cc-by-nc`、`in copyright`
  - 站方请求：无论版权状态，来源都写作 "Wellcome Collection"
- **British Library（Flickr Commons）**：17–19 世纪书籍插图，官方声明已放回公有领域，**不强制署名**（但注明更好）。附加伦理约束：不得篡改，不得用于可能贬损原意境的语境。
- **NYPL Digital Collections**：只用**明确标记为 PD** 的条目。官方原文承认「对未标记的条目，我们不授予也不否认许可」——灰区一律不碰。
- **Gray's Anatomy 1918（第 20 版）**：属公有领域（出版于 1931 年前；作者 Henry Gray 卒于 1861，绘者 H. C. Carter 卒于 1897）。
- **翻拍件规则**：未增强的**平面**作品忠实翻拍不产生新版权（美国 *Bridgeman v. Corel*；英国 *THJ v Sheridan* 2023）。**任何能投下影子的东西（3D 实物照）不适用。** 另注意北欧等地区对「简单照片」有邻接权，故只取未增强的平面扫描。

## 明确不用的来源

| 来源 | 原因 |
| --- | --- |
| Rawpixel | 「Editorial use only」与免费层署名条款使来源记录不干净；当前条款页无法取得 |
| Internet Archive | 官方明示不担保条目版权状态，实测有条目连 `rights` 字段都没有——**不能当作公有领域依据** |
| Flickr Commons 的 NKCR 标记 | 官方原文：既不能授权也不提供担保；PDR 的定义是「基于信息缺失，而非证据存在」 |
| Old Book Illustrations 的**文本** | CC BY-NC-SA 4.0（禁商用），且站方不作版权保证 |
